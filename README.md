# 🤖 MeetBuddy

MeetBuddy is your intelligent AI meeting assistant designed to make meetings smarter, simpler, and more actionable. It offers real-time transcription, smart summarization, action item detection, in-meeting AI chat, and seamless integration with tools like Google Calendar and Jira.

---

## 🚀 Features

- **🎙️ Real-Time Transcription** – Accurate and fast transcription of all your meetings.  
- **🧠 In-Meeting AI Chat** – Ask what you missed, get context instantly.  
- **📝 Smart Summarization** – Get concise and clear meeting notes.  
- **✅ Action Item Detection** – Automatically detects and logs tasks and decisions.  
- **📅 Google Calendar Integration** – Schedules meetings contextually.  
- **📌 Jira Integration** – Auto-creates Jira tasks from action items.

---

## 🛠 Tech Stack

| Tech                 | Purpose                                           |
|----------------------|---------------------------------------------------|
| **React + Vite**     | Frontend framework for a fast, interactive UI     |
| **Tailwind CSS**     | Styling with utility-first design                 |
| **Express.js**       | Backend API and routing                           |
| **Firestore**        | Stores user data, audio recordings, summaries     |
| **Ollama**           | Local/Server LLMs for transcription & NLP         |
| **Google Calendar API** | Schedules meetings seamlessly                  |
| **Jira API**         | Auto-creates tasks from meetings                  |
